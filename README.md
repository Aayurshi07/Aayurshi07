## 🚀 Featured Projects

Every project below follows the same structure: **a business problem, a validated method, and a clear recommendation.**

### 📈 [Sales Forecasting with Facebook Prophet](https://github.com/Aayurshi07/sales-forecasting-prophet)
<img src="https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white"/> <img src="https://img.shields.io/badge/Prophet-0A66C2?style=flat-square"/> <img src="https://img.shields.io/badge/Power%20BI-F2C811?style=flat-square&logo=powerbi&logoColor=black"/> <img src="https://img.shields.io/badge/Time%20Series-5B3FD6?style=flat-square"/>

| | |
|---|---|
| **Problem** | Retailers need to anticipate revenue to plan inventory, staffing and cash flow. |
| **What I did** | Cleaned 541,909 transactions into 52 weeks of revenue data, used a chronological train/test split, built a baseline, then tuned the trend flexibility (`changepoint_prior_scale`) and spotted the overfitting point at 1.0. |
| **Impact** | Forecast error fell from **28.0% to 9.4% MAPE** and MAE from £91.8K to £29.5K. Projected **£5.15M** revenue for the next 12 weeks, with an interactive Power BI dashboard. |
| **Honesty note** | Documented that one year of data cannot capture yearly seasonality, so the model likely overstates early-year revenue. |

### 🔁 [Customer Churn Prediction](https://github.com/Aayurshi07/customer-churn-prediction-logistic-regression)
<img src="https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white"/> <img src="https://img.shields.io/badge/scikit--learn-F7931E?style=flat-square&logo=scikitlearn&logoColor=white"/> <img src="https://img.shields.io/badge/Logistic%20Regression-5B3FD6?style=flat-square"/>

| | |
|---|---|
| **Problem** | Find customers likely to churn before they go silent, so retention can start early. |
| **What I did** | Defined churn (inactive 180+ days) across 4,338 customers, excluded Recency from the features to **avoid data leakage**, and showed that a naive model with 80% accuracy had **0% recall**. Fixed it with scaling and balanced class weights. |
| **Impact** | Churn recall rose from **0% to 91%**. Frequency was by far the strongest churn driver, so the recommendation is to **prioritise repeat purchases over big one-time spenders.** |

### 🎯 [Customer Segmentation (RFM + K-Means)](https://github.com/Aayurshi07/customer-segmentation-rfm-kmeans)
<img src="https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white"/> <img src="https://img.shields.io/badge/K--Means-5B3FD6?style=flat-square"/> <img src="https://img.shields.io/badge/Power%20BI-F2C811?style=flat-square&logo=powerbi&logoColor=black"/> <img src="https://img.shields.io/badge/GenAI-8E75B2?style=flat-square"/>

| | |
|---|---|
| **Problem** | Treating every customer the same wastes marketing budget and loses high-value buyers. |
| **What I did** | Cleaned 541,909 records to 397,884 valid ones, engineered Recency, Frequency and Monetary features, scaled them, chose k=4 with the Elbow Method, and used AI-assisted analysis to write business personas. |
| **Impact** | Four actionable segments. **0.3% of customers are VIPs** driving outsized revenue, while **about 25% are at risk or lost**. Each segment has a targeted playbook, plus an interactive Power BI dashboard. |
